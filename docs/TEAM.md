## Как работаем

- Перед работой `git pull` ветки `main`. Каждый работает в своей ветке и вливает изменения через pull request.
- Pull request вливается, только если CI зелёный (тесты сайта и сервера).
- Чужую папку игры не меняем без договорённости.
- Секреты (ключи, пароли, `.env`) в репозиторий не попадают.
- Код заморожен 22 ноября в 14:00, защита в 15:30.
