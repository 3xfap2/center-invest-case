# Достижения GLITCH (сообщение `achievement`)

Каждое отправляется один раз за прохождение: `{ ns: 1, type: 'achievement', id }`.

| id | Название | Условие |
|---|---|---|
| `gl_first_bug` | Первый баг | Первый отчёт принят |
| `gl_not_a_bug` | Это не баг | Отметил в документации, что часы, которые идут назад, задуманы |
| `gl_reproduced` | Воспроизвёл | Повтор по шагам из журнала воспроизвёл исчезновение журнала |
| `gl_clean_report` | Отчёт с первого раза | Отчёт об исчезновении журнала принят без возвратов |
| `gl_duplicate` | Тот же профиль | Сравнил свой отчёт с отчётом #0412 и нашёл совпадение профиля |
| `gl_chalk` | След в темноте | Нашёл надпись мелом в архиве при свете фонаря |
| `gl_evidence` | Доказательство сохранено | Сохранил запись и отчёт #0412 в терминале дежурного |
| `gl_chapter1` | Первый рабочий день | Прошёл главу 1 |
| `gl_no_hints` | Сам разобрался | Прошёл главу 1 без подсказок |
