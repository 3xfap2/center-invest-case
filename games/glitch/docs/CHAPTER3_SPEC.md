## Контракт панелей (агент «Интерфейс»): `src/ui/ch3panels.js` и `src/ui/ch3panels.css`
Общее для всех четырёх панелей:
- Создаются один раз: `createX(root)`, где root это `#ui`. Корневой элемент с классом `c3-layer`, `position:absolute; inset:0; z-index:40; pointer-events:auto`, затемнение фона.
- При открытии `bus.emit('panel:open', name)`, при закрытии `bus.emit('panel:close', name)` (name: 'timeline' | 'console' | 'hypo' | 'autotest'). Закрытие: крестик, клик по затемнению, `bus.on('input:pause')` (Esc).
- Методы: `open(opts)`, `close()`, `isOpen()`.
- Стиль как у планшета (`src/ui/tablet.css`, классы `tb-`): тёмный рабочий инструмент, системный шрифт, моноширинный только для консоли и кодов. Без неона и стекла. Телефон: панель на весь экран, кнопки от 44 px, прокрутка `touch-action: pan-y`. Тексты по-русски, без длинного тире.

### `createTimeline(root)`
`open({ cards, onSubmit })`. `cards: [{ id, title, text, date }]` (date строка или null).
Пул карточек сверху и 5 пронумерованных слотов «раньше → позже». Нажатие на карточку ставит её в первый свободный слот, нажатие на карточку в слоте возвращает её в пул. Кнопка «Проверить порядок» активна, когда заполнены все слоты; `onSubmit(ids)` возвращает `{ ok, message }` (может быть Promise). Показать message (зелёным или жёлтым). При ok кнопка «Готово» закрывает панель.

### `createConsole(root)`
`open({ commands, onRun })`. `commands: [{ id, label, desc }]`. Чёрный экран с моноширинным выводом (история сохраняется между открытиями), список команд кнопками (на телефоне удобно нажимать) и поле ввода (на ПК можно набрать команду, Enter запускает; подсказка по началу ввода). `onRun(id)` возвращает массив строк или Promise массива; вывести их с префиксом `> команда`. Метод `print(lines)` для вывода извне. Клавиша ` (Backquote) в поле ввода не должна вводить символ, она закрывает консоль (её слушает игра).

### `createHypotheses(root)`
`open({ items, onVerdict })`, `refresh(items)`. `items: [{ id, claim, hint, evidence, verdict }]`: evidence это строка или null, verdict это null, 'true' или 'false'. Карточка на гипотезу: утверждение, под ним «Как проверить» (hint), «Доказательство» (evidence или «пока нет»), кнопки «Верно» и «Неверно», активные только при evidence и пока verdict null. `onVerdict(id, 'true'|'false')` возвращает `{ ok, message }`: при ok показать вердикт зелёной меткой, иначе показать message жёлтым (кнопки остаются).

### `createAutotest(root)`
`open({ blocks, onRun })`. `blocks: [{ id, label }]`. Слева доступные блоки, справа сценарий: нажатие на блок добавляет его в конец сценария, нажатие на блок в сценарии убирает его. Кнопки «Очистить» и «Запустить». `onRun(ids)` возвращает Promise `{ ok, lines, message }`; lines вывести по одной с задержкой ~300 мс как лог теста (зелёные или красные строки), затем message. При ok кнопка «Готово».
