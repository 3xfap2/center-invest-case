# Ресурсы и лицензии

В игре использованы оригинальные процедурные ресурсы, созданные для «Дыма».

| Файл | Ресурс |
| --- | --- |
| `src/world/models.ts` | Пожарная часть, машина, персонажи, здания, мебель, двери, ствол |
| `src/world/effects.ts` | Пламя, дым, искры и струя |
| `src/world/sound.ts` | Синтез звуков дыхания, воды и сигналов рации |
| `src/style.css` | Нашивка, индикаторы и оформление интерфейса |
| `content/calls/01-apartment.json` | План и сценарий квартиры |
| `content/calls/02-kitchen.json` | План и сценарий кафе |
| `content/calls/03-workshop.json` | План и сценарий мастерской |
| `content/calls/04-store.json` | План и сценарий кладовой |
| `content/calls/05-warehouse.json` | План и сценарий склада и молодёжного центра |
| `content/career.json` | Оригинальный пересказ официальных материалов из `docs/SOURCES.md` |
| `../shared/ns-bridge.js` | Общий мост «ПрофНавигатора», скопирован без изменений |

Интерфейс пользуется системными шрифтами Segoe UI, Arial и Consolas с резервными системными шрифтами. Сборка включает код Three.js, React, React DOM и Zod (MIT) и их уведомления о лицензиях. Веб-шрифты, образцы звука, модели и текстуры отдельными файлами не загружаются.
