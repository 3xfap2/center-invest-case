# Дым · Первая смена

Браузерная игра о первой смене пожарного-спасателя в Заречном. Пять вызовов, три сложности, три финала. Настольный браузер, WebGL 2, клавиатура и мышь.

## Запуск

В папке `games/dym`:

```sh
npm ci
npm run dev
```

`npm run build` создаёт `web/public/games/dym/index.html`. Сборку можно открыть напрямую в браузере или встроить на платформу с того же origin. Сохранения находятся в браузере при самостоятельном запуске и передаются платформе через неизменённый `games/shared/ns-bridge.js` при встраивании.

## Управление

| Клавиши | Действие |
| --- | --- |
| WASD, мышь | Движение и обзор |
| ЛКМ | Подача воды |
| E, удерживать | Действие, дверь или подъём пострадавшего |
| Shift, C | Бег, приседание |
| 1, 2, 3 | «За мной», «Держи позицию», «Прикрой водой» |
| F, B, Esc | Тепловизор, снаряжение, пауза |
| X в безопасной зоне | Передать вызов другому расчёту |
| Стрелки или ПКМ, пробел | Дополнительное управление обзором и подачей воды |

Зелёная полоса ведёт к безопасной зоне. В ней восстанавливаются воздух и вода и принимают пострадавших. План в инструктаже показывает точки задач и двери.

## Проверки

```sh
npm test
npm run build
npx playwright install chromium --only-shell
npm run test:smoke
```

Тест браузера использует сборку Vite, ожидает сообщения платформы и проверяет отказ захвата мыши. `DYM_BROWSER` позволяет указать исполняемый файл Chromium. `DYM_GPU=native` запускает тест без принудительного программного WebGL. Параметр `?debug=1` включает выбор вызова и финала. Отладочные вызовы используют отдельную смену и не пишут в сохранения.

Материалы для защиты в `docs/DEFENSE.md`. Источники в `docs/SOURCES.md`. Интеграция проверена во фрейме с тем же origin и доступным мостом. Сверку с полным `docs/GAME_CONTRACT.md` нужно сделать в основном репозитории.
