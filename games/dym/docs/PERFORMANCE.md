# Производительность «Дыма»

Проверено 21 ноября 2026 года на Windows в Chromium Headless 159.0.8154.6. Размер окна 1280×720, масштаб браузера 100%. WebGL подтвердил аппаратный ANGLE Direct3D 11 на встроенной AMD Radeon Graphics (PCI 1002:1636).

| Замер финальной сборки | Результат |
| --- | ---: |
| Размер `index.html` | 935 848 байт |
| Размер того же файла в gzip | 265 736 байт |
| От навигации по локальному HTTP до доступной кнопки старта | 0,47 с |
| Меню, 3,6 секунды анимации | 60,0 кадр/с, p95 16,7 мс |
| Вызов 1 у открытой двери, очаги и непрерывная струя, 3,6 секунды | 60,0 кадр/с, p95 16,7 мс |

FPS рассчитан как число интервалов между вызовами `requestAnimationFrame`, делённое на длительность выборки. p95 рассчитан по отсортированным интервалам. Время загрузки включает навигацию и инициализацию WebGL. Замер по локальному HTTP характеризует запуск без сетевой задержки. Внешние файлы для игры не нужны.

В Chromium Headless использовались параметры `--enable-gpu --use-angle=d3d11 --disable-software-rasterizer`. Для браузерного теста с теми же параметрами задать `DYM_GPU=d3d11`. Номер GPU можно проверить через `UNMASKED_RENDERER_WEBGL` расширения `WEBGL_debug_renderer_info`.

Динамическое разрешение сохраняет полноразмерный HTML-интерфейс. В сцене нет динамических теней. Пламя использует до 256 инстансов, дым до 340 точек, вода до 370, искры до 330. Работают до двух динамических источников света от очагов.
