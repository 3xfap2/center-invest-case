# Источники для профориентационной карточки

Проверено 21 ноября 2026 года.

Действующий устав подразделений пожарной охраны опубликован в [приказе МЧС России № 363](https://mchs.gov.ru/dokumenty/7451).

| Что проверено | Официальный источник |
| --- | --- |
| Дежурный караул готовит снаряжение, выезжает по тревоге, тушит пожары и спасает людей | [МЧС России, старший пожарный о дежурстве](https://89.mchs.gov.ru/deyatelnost/press-centr/novosti/5804249) |
| В непригодной для дыхания среде пожарные работают звеном, в аппаратах и с расчётом запаса воздуха на выход | [Приказ МЧС России № 640, в частности приложение № 3](https://mchs.gov.ru/dokumenty/bazovye-normativnye-pravovye-akty/normativnye-pravovye-akty-mchs-rossii/7455) |
| Горючий материал определяет класс пожара, а электроустановки под напряжением выделены в класс E | [МЧС России, статья 8 Федерального закона № 123-ФЗ](https://10.mchs.gov.ru/uploads/resource/2024-09-04/c1fd584bc932b418e820574405272661.pdf) |
| Вода разбрызгивает горящее масло. Воду нельзя применять к горящему оборудованию под напряжением | [ГУ МЧС России по г. Москве](https://moscow.mchs.gov.ru/rekomendacii-naseleniyu/pozhar-v-kvartire) |
| Ребёнку следует покинуть горящее помещение, позвать взрослых и вызвать пожарных по 101 или 112 из безопасного места | [ГУ МЧС России по Псковской области](https://60.mchs.gov.ru/deyatelnost/press-centr/novosti/5548927) |
| ДГТУ предлагает специалитет 20.05.01 «Пожарная безопасность» в Ростове-на-Дону | [Каталог образовательных программ ДГТУ](https://donstu.ru/abiturient/katalog-obrazovatelnykh-programm/1842/) |
