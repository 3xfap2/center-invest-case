# Ресурсы «Дыма»

| Ресурс | Где используется | Источник и лицензия |
| --- | --- | --- |
| Низкополигональные здания, мебель, люди, снаряжение и заставка | Пять вызовов и главное меню | Оригинальная процедурная геометрия для проекта, в исходном коде |
| Пламя, дым, струя, искры и тепловизор | Сцены вызовов | Оригинальные процедурные эффекты, в исходном коде |
| Рация, вода, дыхание и сигналы | Вызовы и переходы | Оригинальный синтез через Web Audio, в исходном коде |
| Кириллическая типографика | Интерфейс | Системные шрифты, файлы шрифтов в сборку не входят |
| Мост платформы | Встроенный режим | Имеющийся games/shared/ns-bridge.js, без изменений |
| Three.js, React, React DOM, Zod | Игровая сборка | MIT, тексты лицензий включаются в HTML |
