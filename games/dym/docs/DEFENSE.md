# Защита «Дыма»

- **Почему Three.js.** Он даёт перспективную камеру, инстансинг, туман и простой WebGL-рендер. React отвечает за меню и HUD. Vite объединяет их в один HTML.
- **Почему симуляция отдельно.** Правила не зависят от браузера, сцены и частоты кадров. Игрок обновляется с шагом 50 мс, сетка с шагом 250 мс. Seed определяет начальную горючесть клеток.
- **Как работает огонь.** Ячейки хранят температуру, топливо, дым и влагу. Соседи обмениваются жаром и дымом. Двери меняют связь между ячейками. Струя летит по дуге к очагу, охлаждает и оставляет влагу. Плита и проводка требуют специальных действий.
- **Как держим частоту кадров.** Геометрия объединена в инстансы. Пламя рисуется одним набором инстансов, дым и вода ограничены, динамических теней нет. Разрешение сцены подстраивается под время кадра. См. `PERFORMANCE.md`.
- **Как добавить вызов.** Добавить JSON в `content/calls/` со следующим номером, планом, очагами, людьми, задачами и репликами. Загрузчик подхватит его автоматически. Zod проверяет форму, координаты и связность плана.
- **Как проверили.** Vitest покрывает огонь, воду на опасных материалах, воздух, взаимодействия, эвакуацию, бюджет, сохранения и финалы. Один тест проводит игрока по всем пяти картам. Playwright проверяет реальную сборку во фрейме.
- **Что сохраняется.** Имя в эфире, сложность, бюджет, два сюжетных решения и результаты завершённых вызовов. Из персональных данных только псевдоним. Состояние посреди вызова не сохраняется.
- **В чём идея.** Знакомые темп, прицел, подготовка и работа в команде служат спасению. Время задаёт воздух, ценность команды заметна в финале. В карточке профессии подросток видит реальные действия при пожаре и профессиональный путь.
- **Сколько весит.** Сжатая передача около 0,27 МБ. Методика измерения и результат загрузки в `PERFORMANCE.md`.
