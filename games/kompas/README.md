# Компас

Три дня летнего лагеря на Дону. Игрок распределяет подростков по мастерским, наблюдает за их реакциями и предлагает каждому следующую пробу.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install chromium
npm run test:smoke
```

Сборка создаёт `web/public/games/kompas/index.html` в корне репозитория. Готовый HTML можно открыть и напрямую с диска. Перед браузерным тестом соберите игру. Переменная `KOMPAS_BROWSER` позволяет выбрать другой Chromium-совместимый исполняемый файл.

## Как играть

- Щёлкни по школе и возьми у Галины Петровны дневник. Это обязательный шаг перед занятиями.
- Щёлкни по любой локации, чтобы узнать, что там происходит, какой навык ребята тренируют и что даёт посещение.
- Перетащи портрет каждого участника на домик. Также можно выбрать портрет и щёлкнуть по мастерской.
- ПКМ вращает макет. Колесо меняет масштаб. Щелчок по домику плавно приближает камеру.
- Занятие длится 45 секунд. Щёлкай по участнику, пока над ним виден знак эмоции. Очки возвращаются утром.
- После трёх занятий задай один вопрос у фонаря. В третий день подготовь по карточке для каждого участника.
- Esc или кнопка в шапке открывает паузу. В автономной игре сложность и ник доступны в шапке.
- `?debug=1` открывает отладку со всеми днями, слотами, скрытыми профилями и финалами.

## Структура

`src/camp` содержит правила и Zod-схему. `content/camp.json` описывает персонажей, мастерские, диалоги и опрос. `src/view` отрисовывает лагерь и интерфейс. `content/career.json` содержит карточку профессии.

Материалы для защиты находятся в [docs/DEFENSE.md](docs/DEFENSE.md). Источники и ассеты описаны рядом.
