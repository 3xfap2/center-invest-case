# Компас · Ассеты и лицензии

| Файл | Содержимое | Источник |
|---|---|---|
| `src/view/models.ts` | Геометрия лагеря, фигурки, реквизит и светильники | Оригинальная работа для «Компаса». |
| `src/view/world.ts` | Знаки эмоций Canvas, свет и анимации | Оригинальная работа для «Компаса». |
| `src/view/illustration.ts` | Портреты, картинки опроса и эпилога | Оригинальная работа для «Компаса». |
| `src/view/soundtrack.ts` | Инструментальная тема «Тихий Дон» | Оригинальная композиция и синтез для «Компаса». |
| `src/view/audio.ts` | Синтез берегового шума и сигналов | Оригинальная работа для «Компаса». |
| `src/style.css` | Типографика и оформление | Системные Georgia и Segoe UI. Файлы шрифтов не включены. |
| `bridge/ns-bridge.js` | Резервная байтовая копия моста платформы для автономной сборки | Репозиторий команды. В общем репозитории сборка берёт `../shared/ns-bridge.js`. |

Three.js, React, React DOM, Scheduler и Zod распространяются по лицензии MIT. Их тексты лицензий включены в HTML-сборку. В игре нет внешних изображений, моделей, звуков и сетевых запросов за ресурсами.
