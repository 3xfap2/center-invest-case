# Ответы на защите

- **Почему Three.js?** WebGL рисует офисный этаж и ригованных персонажей. PointerLockControls обрабатывает обзор мышью, простые коллайдеры ограничивают движение, а луч находит предмет в пределах двух метров.
- **Как подключается к сайту?** Vite встраивает общий `games/shared/ns-bridge.js` без изменений. Сайт передаёт `init`. Игра отправляет прогресс, контрольные точки, флаги и результат. Тот же HTML открывается напрямую.
- **Зачем отделять расследование от сцены?** Чистый TypeScript в `src/case` отвечает за время, улики, решения, отчёт и сохранение. Three.js строит этаж, React показывает панели на мониторе, субтитры и отчёт. Эти слои используют общий API дела.
- **Как данные управляют сюжетом?** Zod проверяет `content/case.json`. В нём описаны операции, условия этапов, улики, зависимости заданий, связи и аргументы отчёта. Тексты и финалы лежат в `content/dialogue/chapter.json`.
- **Как устроены инструменты?** При посадке HTML проецируется на геометрию экрана; карточки и нити на доске являются 3D-объектами. Количество улик и правильность связи приходят из движка расследования.
- **Что проверяется?** Vitest проверяет связи, время, вопросы, физические задания, честный возврат, финалы и восстановление сейва. Playwright проверяет движение, взаимодействие, кириллицу, сцену отчёта, iframe и запуск файла напрямую.
- **Размер и загрузка.** Однофайловая сборка включает шрифт и пять компактных GLB. Gzip-размер печатает `npm run build`. Для программного WebGL включается более низкое разрешение рендера.
- **Что сохраняется?** Эпизод, осмотренные операции, улики, ответы, выполненные задания, связи, решения, время и отчёт. Никнейм виден из `init`. Сейв не содержит персональных или банковских реквизитов игрока. Хранением занимается платформа.
- **Как продолжить историю?** Платформа передаст флаги главы 1 через `init`. По ним глава 2 сможет учесть судьбу Дани, фестиваля и качество отчёта. Значения описаны в `FLAGS.md`.
