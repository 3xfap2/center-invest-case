# Чужое имя · Три часа до оплаты

Первая глава игры от лица стажёра банковского антифрода. До оплаты оборудования для фестиваля осталось три часа. Дойди до звонящего телефона и проверь, кто на самом деле получит перевод.

## Запуск из папки игры

```sh
npm ci
npm run dev
npm test
npm run build
```

Итоговый `../../web/public/games/chuzhoe-imya/index.html` открывается напрямую и работает в iframe сайта. Он содержит этаж, модели, звук и шрифт.

```sh
npx playwright install chromium
npm run test:smoke
```

Проверка Playwright использует последнюю сборку. `CHUZHOE_BROWSER_CHANNEL=msedge` выбирает установленный Edge.

Щёлкни «Нажми, чтобы начать смену». Мышь осматривает этаж, WASD перемещает, Shift ускоряет ходьбу, E взаимодействует с предметом под прицелом, Tab открывает задачи, Esc открывает паузу. Игровые минуты списываются только за действия из дела.

Режим `?debug=1` открывает меню на F2. F3 ставит игрока рядом с текущей целью, сохраняя расследование. Из меню можно перейти к любому эпизоду, открыть улики или показать любой финал.


Зелёные стрелки на полу и компас ведут к каждой цели. На доске можно выделить рекомендуемую пару карточек. После сдачи отчёта у ресепшена открывается лифт на этаж −1 с четырьмя архивными заданиями. В самостоятельной веб-версии контрольные точки сохраняются в этом браузере.


Русские реплики включаются после старта, у озвученных сцен есть субтитры и кнопка «Повторить реплику». Звук управляется через меню Esc.

Для обновления записей при изменении диалогов запусти `python scripts/generate-voices.py путь_к_моделям` с `piper-tts` версии 1.5 или новее и `imageio-ffmpeg`. Имена и источники моделей указаны в `docs/ASSETS.md`.
